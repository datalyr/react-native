# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub:

1. Open the [Security tab](https://github.com/datalyr/react-native/security) of this repository.
2. Select **Report a vulnerability**.
3. Write the problem, the affected versions and the steps to reproduce it.

We reply to your report and tell you when a fix is released.

## Supported versions

We fix security problems in the latest release. Update to the latest version to get fixes.
